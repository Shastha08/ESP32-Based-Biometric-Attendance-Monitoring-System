# ESP32-Based-Biometric-Attendance-Monitoring-System
IoT-Based Fingerprint Attendance System using ESP32 and R307S sensor. It uses DS3231 RTC for date and time, LCD for status display, and Wi-Fi to automatically upload attendance records (IN/OUT) to Google Sheets.
